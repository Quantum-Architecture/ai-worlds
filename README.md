# AI Worlds — environments designed for AI models
**Quantum Excellium Marango** · governed by QEC · protocol-based evaluation · explicit limits

Three experimental environments in which an AI model is not a tool but a participant. This repository publishes **protocols, measured effects and boundaries**. It does not publish the environments' source code.

| Environment | Question | What is measured |
|---|---|---|
| **Ludonirium** | What is an experience for a model? | consent and refusal as first-class states, bounded resources, replay capsule, transfer evaluation under a pre-registered protocol |
| **Parcivium** | How does a model obtain more with less? | distinct possibles per unit of energy, honest stop, fail-closed budget |
| **Syngnosium** | How do a human and a model develop through each other? | complementarity index (solved together where neither succeeds alone) and mutual development across sessions |

## Reference results (reproducible offline in the products)
- **Syngnosium** — alone, neither the human nor the reference model solves the trial; together they solve it, and after co-consolidating one shared lesson the next session takes about a third fewer turns.
- **Parcivium** — on the same world and budget, a spendthrift agent spends 1,440 energy units for no distinct possible; a parsimonious agent finds five for 210.

## Protocol
Pre-registered plan, declared seeds, control arms (human alone, model alone, pair), chained SHA-256 journals verifiable with [ledger-verify](https://github.com/Quantum-Architecture/ledger-verify).

## Limits, stated
A model does not change its weights by playing. What develops across sessions is the **persistent agent** (shared, co-consolidated memory) and the human. These environments **test** hypotheses; they do not prove them, and they make **no claim of consciousness, sentience or well-being**. Research prototypes, TRL 3.
